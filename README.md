# Motionshelf

Animated React components for sites that sell: payment notifications, chat
flows, map pins, search results and more. Built with React, Tailwind and GSAP,
installed as code you own through the shadcn registry.

## Develop

```bash
pnpm install
pnpm dev
```

The site lives in `app/[locale]` (English at `/en`, Portuguese at `/pt`).
Translations are in `messages/`.
